# Event Planning Framework

Reference for Procedure 3 (Event & Training Planner).

---

## Event Types

| Type | Typical Duration | Audience | Key Feature |
|---|---|---|---|
| Workshop | 3–4 hrs | Hygienists, dentists | Skill-focused, station-based |
| CPD Day | 6–8 hrs | Mixed clinical | Full ODPF programme, CPD credits |
| Certification Day | 6–8 hrs | Practitioners seeking iTOP cert | Competency gate assessments required |
| Study Club | 1.5–2 hrs | Small peer group | Peer feedback + protocol review |
| Onboarding | 2–3 hrs | New staff/students | iTOP philosophy introduction + first skill |

---

## 60/40 Rule

Every event must allocate ≥60% of total time to hands-on practical work.
If topic list cannot achieve this, flag the event plan:
```
⚠ HANDS-ON FLAG: Current topic list achieves {X}% hands-on — minimum 60% required.
   Recommendation: Reduce theory blocks or extend total event duration.
```

---

## Station Setup Guidelines

- Maximum 4 participants per station (ensures instructor can physically coach each person)
- Each station requires: typodont/phantom, full instrument kit, disclosure tablets, handout
- Stations rotate every {topic duration} minutes with 5 min transition buffer
- Label stations clearly: Station name, skill focus, equipment list

Station map format:
```
STATION MAP
  [ Station 1: Modified Bass ]    [ Station 2: Interdental ]
    Equipment: typodont, brush      Equipment: typodont, floss,
    kit, disclosure tablets         interdental brushes
    Max: 4 participants             Max: 4 participants

  [ Station 3: BOB Measurement ]  [ Station 4: Debrief / Feedback ]
    Equipment: BOB App device,      Equipment: whiteboard, flip chart
    typodont with simulated BOB     Max: full group
    Max: 4 participants
```

## Pre-Event Prep Timeline

| Checkpoint | Tasks |
|---|---|
| T-4 weeks | Confirm venue, participant count, equipment inventory, facilitator assignments |
| T-1 week | Send pre-reading to participants, confirm equipment deliveries, print handouts |
| T-1 day | Set up stations, test BOB App devices, brief facilitators on station rotations |
| Day-of | Arrival 60 min early, final station check, participant registration, welcome brief |

## Post-Event Evaluation

Collect from all participants immediately after event:

```
POST-EVENT EVALUATION
  1. Which station was most valuable? Why?
  2. What technique felt most difficult? What would help?
  3. What would you do differently with your next patient?
  4. What should be covered in more depth next time?
  5. Overall rating: {1–5}
  6. Open comments:
```

Route completed evaluations to Feedback Synthesizer (Procedure 4) for analysis.
